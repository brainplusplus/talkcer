# Talkcer — Definition of Done

Sebuah task dianggap selesai jika:

1. Kode mengikuti architecture dan API contract.
2. Semua acceptance criteria terpenuhi.
3. Unit/integration test lulus.
4. Tidak ada warning build yang baru.
5. Error state dan loading state ditangani.
6. Data tersimpan sesuai schema.
7. Dokumentasi diperbarui bila contract berubah.
8. Tidak ada secret, API key, atau data user yang di-hardcode.
9. Fitur dapat dijalankan secara lokal.
10. Perubahan tidak merusak task sebelumnya.
11. Untuk overlay: hide/show, session switching, dan preference persistence teruji.
